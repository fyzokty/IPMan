# User Stories

- As a user, I want to see every relevant adapter as a tab so I can manage the
  correct interface without opening Windows Settings.
- As a user, I want connection state shown with icon and text so I can understand
  it at a glance.
- As a technician, I want to configure an adapter even when it is disconnected
  so I can prepare settings before connecting a cable.
- As a user, I want IP fields validated while typing so invalid addresses are
  caught before Windows is changed.
- As a user, I want optional gateway/DNS so direct-device networks are easy to
  configure.
- As a technician, I want reusable profiles so I can switch between common
  networks quickly.
- As a cautious user, I want profile selection to fill fields without applying
  them automatically.
- As a power user, I want an option to auto-apply selected profiles.
- As a user, I want IPMan to warn when an IP might already be in use.
- As a user, I want Windows state reread after every apply so the UI tells me
  what actually happened.
- As a user, I want rollback so a bad change can be reversed quickly.
- As a user, I want favorite profiles first so common configurations are faster.
- As a user, I want profile search to match name, description and IP values.
- As a user, I want import/export because profiles are intentionally portable
  JSON files.
- As a user, I want corrupt profiles isolated so one bad file does not break the
  app.
- As a user, I want adapters and profile folders monitored so the UI updates
  without manual refresh.
- As a user, I want the app to remember window/tray preferences so repeated use
  feels consistent.
- As a user, I want the UI to follow Windows theme or use a forced light/dark
  theme.
- As a support user, I want copyable diagnostics so troubleshooting is faster.
