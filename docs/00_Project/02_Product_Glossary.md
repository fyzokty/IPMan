# Product Glossary

| Term | Meaning in IPMan |
|---|---|
| Adapter | A Windows network adapter exposed for management by the application. |
| Selected Adapter | The adapter represented by the currently active tab. |
| Connected | Windows reports the adapter/link as operationally connected. |
| Disconnected | Windows reports no active link/connection. Configuration may still be edited. |
| Static Configuration | Manually configured IPv4 settings. |
| DHCP | Automatic IP configuration. |
| Profile | A reusable saved IPv4/DHCP configuration stored as a standalone JSON file. |
| Favorite | A profile pinned above regular profiles. |
| Current Configuration | Values freshly read from Windows for an adapter. |
| Edit Configuration | Values currently present in the editable controls before application. |
| Rollback Snapshot | Configuration captured immediately before a change for recovery. |
| Profile Comparison | Visual comparison between current adapter values and selected profile values. |
| System Tray | Windows notification area where IPMan may continue running when hidden. |
| Critical Log | Technical failure record needed for troubleshooting, not routine activity history. |
