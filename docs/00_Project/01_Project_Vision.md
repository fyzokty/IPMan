# Project Vision

IPMan should feel like a small native Windows utility: immediate, predictable
and unobtrusive.

The central experience is one main window containing one tab per visible network
adapter. The selected tab shows the real current adapter state and provides the
editing controls for that exact adapter.

The product should reduce repetitive network reconfiguration work without hiding
important consequences from the user. Fast workflows are supported through saved
profiles, favorites and optional one-click profile application, but the default
behavior remains conservative: selecting a profile fills the editing fields and
the user chooses when to apply it.

The product is fully usable without Internet access.

## Experience goals

- Startup shows the actual Windows configuration.
- Adapter insertion/removal appears automatically.
- Clear connected/disconnected icon and text are always visible.
- Static/DHCP state is immediately understandable.
- Editing controls are simple text boxes with copy actions.
- Existing values can be restored into editing fields with one action.
- Profiles are searchable and portable.
- Changes are reversible.
- Errors are understandable without hiding diagnostic detail from support use.

## Product identity

Display name: **IPMan**

Meaning: **IP Manager**

Initial UI language: Turkish.

Localization architecture: required from first implementation.
