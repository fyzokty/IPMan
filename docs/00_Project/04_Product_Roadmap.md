# Product Roadmap

## Release 1.0

Committed scope:
- Windows 10/11 x64.
- Administrator execution.
- Single-instance behavior.
- Single main window.
- Adapter tabs with connection icon + text.
- Multiple adapter support.
- Current IPv4/mask/gateway/DNS/DHCP/link information.
- Adapter description and MAC display.
- Static IPv4 application.
- DHCP application.
- Optional DNS values.
- Live validation.
- Conflict warning using best-effort reachability check.
- Post-apply Windows verification.
- Rollback.
- Profiles stored as individual JSON files.
- Favorite profiles.
- Profile search.
- Profile import/export.
- Duplicate-name numbering.
- Malformed-profile handling.
- Current/profile comparison.
- System tray behavior.
- Settings dialog.
- Windows/Light/Dark theme selection.
- Turkish UI with localization infrastructure.
- Critical-error logging.
- Crash marker / previous unexpected termination notice.
- Diagnostic information panel.
- Portable and installer distributions.

## Deferred beyond 1.0

- IPv6 configuration.
- Cloud synchronization.
- Remote host management.
- Automatic online update service.
- Multi-profile ZIP export.
- Profile version history.
